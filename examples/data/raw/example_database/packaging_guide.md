# Packaging Station Guide

The packaging station is the final stage of the Widget Assembly Line.

## Procedure

1. Confirm the unit passed calibration (torque within 4.2 ± 0.1 N·m).
2. Apply the lot label printed at intake.
3. Seal the unit in a static-shielding bag.
4. Place 12 units per tray; 8 trays per pallet.

## Common issues

- **Label misprint** — reprint from the intake record using the lot number.
- **Seal failure** — check the heat-seal temperature (should be 140 °C).

Throughput target: 120 units per hour, matching the line rate.
